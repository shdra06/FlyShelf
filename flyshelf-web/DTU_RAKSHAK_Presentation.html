01 / Overview

Executive Summary

Replacing manual logbooks with edge computer vision to log, verify, and secure every vehicle sighting.

03 / Integration

System Architecture

Visualizing the real-time data pathway from high-definition field cameras to web dashboards.
  • 1. Edge Node (Raspberry Pi 5)

    Captures continuous frames, extracts normalized plate text, and POSTs payload with a cryptographic shared secret key.

  • 2. API Gateway (Node/Express)

    Validates edge identities, performs deterministic queries in Redis caching, and stores audit trails in PostgreSQL.

  • 3. Admin Dashboard (React/WS)

    Listens via active WebSockets, pushing instant UI indicators and alarms straight to physical guard tablet interfaces.

04 / Feasibility

Technical Feasibility Matrix

Evaluating standard assets against physical recommendations required for sub-second system logs.

Standard Campus Infrastructure

  • • Standard dome cameras (blur license plates at high speeds)
  • • Edge CPU inference (~4 to 7 seconds per visual parse)
  • • Fluctuating gate Wi-Fi/cellular signals (packet drops)

Rakshak Recommended Spec

  • • High-definition Zoom/Varifocal IP cameras
  • • Raspberry Pi 5 (4GB Version) edge boards
  • • Dedicated PoE switches & fiber-optic runs

Key Decision: Raspberry Pi 5 edge boards are recommended. Running heavy visual transformers on standard gate CPUs causes significant queues and traffic bottlenecks at the gates.

07 / Security

Zero-Trust Cryptographic Architecture

How RAKSHAK matches high-performance database searches while maintaining total privacy.

    Handles gate rush hours easily. Processes hundreds of plate scans per minute without lagging or slowing down traffic.
