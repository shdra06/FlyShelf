───────────────────────────────────────────────────────────────────
  IMAGE EDITING FEATURES (New — requires SixLabors.ImageSharp)
───────────────────────────────────────────────────────────────────

Library: SixLabors.ImageSharp (Apache 2.0 license — no copyleft)
NuGet:   dotnet add package SixLabors.ImageSharp

[ ] Image Cropping
    - Interactive crop overlay in QuickLook window with drag handles
    - Crop to selection, crop to aspect ratio presets (1:1, 4:3, 16:9)
    - Save cropped image as new file or overwrite original

[ ] Image Resizing
    - Resize to specific dimensions or percentage
    - Maintain aspect ratio option
    - Batch resize for multiple selected images

[ ] Image Flipping / Mirroring
    - Horizontal flip
    - Vertical flip
    - Add flip buttons next to existing Rotate button in QuickLook

[ ] Image Filters & Adjustments
    - Brightness / Contrast sliders
    - Grayscale conversion
    - Blur / Sharpen
    - Sepia / Invert
    - Auto-enhance (auto levels)

[ ] Image Format Conversion
    - Right-click context menu: "Convert to PNG / JPG / WebP / BMP"
    - Batch format conversion for multiple selected images
    - Quality slider for JPEG compression

[ ] Image Compression / Optimization
    - Reduce file size while maintaining quality
    - Show before/after file size comparison

    - Show size reduction percentage

[ ] PDF Thumbnails
    - Generate thumbnail previews for PDF files in clipboard history
    - Replace current WebBrowser-based preview with native rendering

───────────────────────────────────────────────────────────────────
  UI / ANIMATION / THEME IMPROVEMENTS (No new dependencies needed)
───────────────────────────────────────────────────────────────────

Design Reference: flyshelf_ui_design_bible.md (in Gemini brain folder)
Inspiration: Rainmeter skins (Mond, Frost Glass, Droptop 4),
             Paste (macOS), Fluent Design 2, Discord/Spotify dark mode

--- Phase 1: Quick Wins (Biggest Visual Impact) ---

[ ] Window Show/Hide Animation
    - Add QuinticEase opacity (0→1) + scale (0.96→1.0) storyboard
    - Duration: 250ms show, 180ms hide
    - Currently MainWindow has Opacity="0" with no storyboard (abrupt)

[ ] Tab/View Transition Animations
    - Crossfade (opacity) between clipboard/notes/settings/network views
    - Duration: 300ms, CubicEase EaseInOut
    - Currently tabs switch instantly with no transition

[ ] Color Transitions on Hover
    - Replace instant property setters with ColorAnimation (150ms)
    - Smooth fade between normal → hover → pressed background colors
    - Currently all hover effects use instant triggers

[ ] Copy Confirmation Flash
    - Brief green tint (#22C55E at 20% opacity) on card when copied
    - 150ms fade-in, 500ms hold, 300ms fade-out
    - Gives satisfying visual feedback

--- Phase 2: Polish (Premium Feel) ---

[ ] Item Entrance Animation
    - New clipboard items slide down + fade in (300ms)
    - Use BackEase EaseOut with Amplitude=0.3 for subtle spring
    - TranslateY from -12 to 0 + Opacity 0 to 1

[ ] Skeleton Shimmer Loading States
    - For image thumbnails while loading
    - Gradient sweep animation (1500ms loop, SineEase)
    - Replace empty space with animated placeholder

[ ] Animated GlassTheme Hover States
    - GlassTheme.xaml currently uses instant triggers
    - Add ColorAnimation storyboards for glass card hover/press
    - Smooth glass border brightness change on hover

[ ] DropShadow Elevation on Hover
    - Cards "lift" with animated shadow (BlurRadius 8→16, Opacity 0.25→0.35)
    - Duration: 150ms hover in, 200ms hover out
    - Creates depth/layering feel like Rainmeter widgets

[ ] Search Bar Focus Animation
    - Expand width slightly + glow border on focus
    - Accent color border fade-in (CubicEase, 200ms)

--- Phase 3: Delight (Competitive Edge) ---

[ ] Spring/Bounce Animations
    - BackEase for item entrance, slight overshoot on selection
    - ElasticEase for special interactions (pin, unpin)
    - Adds playful premium feel

[ ] Ambient Glow on Selected Card
    - Subtle indigo (#6366F1) outer glow on selected item
    - Like Rainmeter's neon accent effects
    - Opacity animation on selection change

[ ] Smooth List Reorder
    - Animated repositioning when items are pinned/unpinned
    - Items slide to new positions instead of instant jump
    - Duration: 250ms, CubicEase EaseInOut

[ ] Context Menu Entrance
    - Fade + scale from click point (200ms)
    - Currently appears instantly

[ ] Theme-Aware Accent Extraction
    - Pull dominant color from wallpaper for adaptive accent
    - Rainmeter skins do this — wallpaper bleeds into UI
