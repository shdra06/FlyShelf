## 1. Introduction

FlyShelf ("the App") is a cross-device clipboard manager that syncs clipboard content between your personal devices. This privacy policy explains what data FlyShelf accesses, how it is stored, how it is shared, and how you can control or delete it.

**FlyShelf is designed with a privacy-first architecture.** The App does not collect analytics, does not track users, and does not sell or share personal data with third parties.

---

## 2. Data We Access

### 2.1 Clipboard Content
FlyShelf monitors your Windows clipboard to capture text, images, files, and URLs that you copy. This is the core functionality of the App.

- **Storage:** All clipboard data is stored **locally** on your device in `%AppData%\FlyShelf\`.
- **Retention:** Configurable retention period (default: 7 days). You can set it to 1, 7, 14, or 30 days, or disable auto-cleanup entirely.
- **Maximum Items:** Up to 500 clipboard items are stored. A warning appears at 150 items.

### 2.2 Device Information
- **Device Name:** Your Windows computer name (configurable in settings).
- **Device ID:** A randomly generated identifier (e.g., `PC_a1b2c3d4e5f6`). This does NOT contain your Windows username.

### 2.3 Network Information
- **Local IP Addresses:** Used for LAN device discovery and direct peer-to-peer connections.
- **Cloudflare Tunnel URLs:** Temporary URLs generated by Cloudflare's `trycloudflare.com` service for remote access. These URLs are ephemeral and change each session.

### 2.4 Firebase Anonymous Authentication
- FlyShelf uses **Firebase Anonymous Authentication** to authenticate with Firebase Realtime Database.
- This creates an anonymous user ID (no email, no password, no personal information).
- The anonymous auth token is stored locally, encrypted with Windows DPAPI.
- Firebase is used **only** as a signaling service for device discovery — clipboard content is **never** stored in Firebase.

### 2.5 Optional: Gemini API Key
- If you choose to use the AI-powered table extraction feature, you provide your own Google Gemini API key.
- This key is stored locally, encrypted with Windows DPAPI.
- The key is sent only to Google's Gemini API endpoint when you explicitly trigger table extraction on an image.

## 3. How Data Is Shared Between Your Devices

### 3.1 Peer-to-Peer Sync
When you pair devices using QR codes or pairing codes:
- Clipboard content is transferred **directly** between your devices via encrypted peer-to-peer connections.
- All data in transit is encrypted using **AES-256-GCM** with keys derived from your unique pairing secret via PBKDF2-SHA256 (100,000 iterations).
- Data passes through your local network (LAN) or through a Cloudflare tunnel — but is always encrypted end-to-end.

### 3.2 Firebase Signaling (Discovery Only)
- Firebase is used as a "phone book" for device discovery: your devices exchange their network URLs through Firebase so they can find each other.
- These URLs are **AES-256-GCM encrypted** before being stored in Firebase.
- **No clipboard content is ever stored in Firebase.**
- Discovery entries are automatically cleaned up after device disconnection.

### 3.3 Cloudflare Tunnels
- FlyShelf uses Cloudflare's free `trycloudflare.com` tunnel service to enable remote connectivity.
- Traffic passes through Cloudflare's network but is encrypted with AES-256-GCM at the application layer.
- Cloudflare cannot read the encrypted payload.
- Tunnel URLs are temporary and change each session.

## 5. Data Storage & Security

| Data | Storage Location | Encryption | Retention |
|---|---|---|---|
| Clipboard History | `%AppData%\FlyShelf\clipboard_history.json` | At-rest (file system ACLs) | Configurable (1-30 days) |
| Clipboard Images | `%AppData%\FlyShelf\Images\` | At-rest (file system ACLs) | Configurable (1-30 days) |
| Settings & Preferences | `%AppData%\FlyShelf\config.json` | Plaintext (non-sensitive settings) | Until app uninstall |
| Gemini API Key | `%AppData%\FlyShelf\config.json` | DPAPI-encrypted | Until user removes it |
| Firebase Auth Token | `%AppData%\FlyShelf\firebase_auth.dat` | DPAPI-encrypted | Until app uninstall |
| Paired Device List | `%AppData%\FlyShelf\paired_devices.json` | At-rest (file system ACLs) | Until user unpairs |
| Application Logs | `%AppData%\FlyShelf\Logs\` | Plaintext | Auto-rotated (500 lines max) |
| Synced Files | `%AppData%\FlyShelf\SyncedFiles\` | At-rest (file system ACLs) | Until user deletes |
| TLS Certificate | `%AppData%\FlyShelf\server.pfx` | PFX password-protected | Until app uninstall |

### Security Measures
- **Encryption in Transit:** AES-256-GCM with PBKDF2-SHA256 derived keys
- **Encryption at Rest:** Windows DPAPI for sensitive credentials
- **Authentication:** PIN-based auth for web clients, pairing-key auth for native clients
- **Rate Limiting:** Protects against brute-force PIN guessing
- **Binary Integrity:** SHA-256 verification for updates and third-party binaries
- **CORS Protection:** Restricted to trusted origins only (localhost, LAN, Cloudflare tunnel)

## 8. Your Rights & Data Deletion

### View Your Data
All data is stored locally in `%AppData%\FlyShelf\`. You can browse these files at any time.

### Delete Your Data
- **Clipboard History:** Use the "Clear All" button in the App, or delete `%AppData%\FlyShelf\clipboard_history.json` and the `Images` folder.
- **Paired Devices:** Unpair devices from Settings, or delete `%AppData%\FlyShelf\paired_devices.json`.
- **All Data:** Uninstall the App and delete the `%AppData%\FlyShelf\` folder.
- **Firebase Data:** Your anonymous Firebase identity is automatically cleaned up by Firebase after inactivity. No personal data is stored.

### Opt-Out of Sync
You can disable all network features by turning off:
- Cloud Discovery
- LAN Sync
- Global Cloudflare Tunnel

This makes FlyShelf function as a purely local clipboard manager with zero network activity.
